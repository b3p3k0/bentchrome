This file guides Claude Code (claude.ai/code) when working in this repository.

## Project Overview

**Bent Chrome** is a top-down vehicular combat game built in Godot 4.7. As of June 2026 it is a clean-slate rebuild: an earlier prototype was retired to `legacy/` (reference only, excluded from the engine by `legacy/.gdignore`). The design, art, and data carried over — the code did not.

### Key design elements
- Top-down view with fake depth (drop-shadows + height for jumps/pits, terraced floors with driveable ramps); 16-bit grimy dystopian style. **Language: JUMP PADS launch you airborne; RAMPS are driveable slopes between floors.**
- Arcade driving with inertia, drift, and surface-based handling; each vehicle feels distinct (motorcycle vs land-yacht).
- Vehicles rendered as **procedural per-car bodies** (`vehicles/car_paint.gd` = registry + core; one `vehicles/paint/<id>.gd` per silhouette — a STYLE metrics dict + static `paint()` drawing with the shared `paint/parts.gd` palette/primitives; adding a car = one file + one registry line, checklist in `docs/car_authoring.md`): bike + rider, muscle car, cop SUV with flashing light bar, 8-wheel APC, … with the visual quantized to **16 compass steps** (`Vehicle.HEADING_STEPS`, 0 = smooth) for the directional-sprite feel. Each STYLE also carries the car's footprint metrics — collision radius (smallest bike → largest monster truck, locked by `tests/test_car_paint.gd`, contract-linted by `tests/test_roster_contract.gd`), skid contact points, steering wheels — so gameplay agrees with the art. Shared procedural taillights are dark crimson at rest and bright red only while throttle opposes signed travel (`DrivingController.service_braking`); handbrake never lights them, and the flag mirrors over LAN. The whole fleet renders at `CarPaint.FLEET_SCALE` (1.25) while **collision radii stay 1:1** — hitbox-smaller-than-visual is deliberate (arcade near-miss forgiveness; radius-coupled AI test budgets) — don't "fix" the split.
- Weapons: a **machine gun** (infinite, car-relative, low chip damage; **overheats** — sustained fire locks it until it cools) plus a **selectable secondary** slot (`WeaponRack`: special / fire / homing / power / rear missile / two mines; cycle mouse wheel or `/`, fire RMB, MG on LMB, handbrake LCtrl, camera zoom toggle G — E and Q deliberately unbound/reserved; auto-cycles off a dry slot). Specials **recharge** to a per-car cap (authored in `roster.json`); missiles are **pickup-fed** (arena ammo crates: M/H/P/R). Missile quartet: fire = medium damage + moderate homing, homing = light damage + aggressive homing, power = heavy damage dead straight, rear = Fire Missile stats and guidance but blue and launched from the tail (`WeaponDef.launch_side`). Rear missiles start at 0/cap 6. **Mines** (2 more slots, start at 0, crate-fed): land mine = damage + 5-45° course deviation; jump mine = no damage, airborne pop + 45-80° re-vector — both deploy from the REAR (Kind.DROP). Everything except the rear missile and DROP weapons launches forward from the nose; guidance (homing), launch side, and cover-piercing are per-weapon data. **All twelve signature specials are live** — PROJECTILE ones are pure data, BEAM (Taser) / DASH (Leap) / TRIGGER (Toe Jam) / FLAME (Blunt Blaze) / DROP (mines) / TORNADO (Tornado Alley — 3s self-centered spin AoE, visual whirls past the 16-step quantizer, steer cut to 0.3, caught cars take the mine spin-out + shove once each, random exit heading; AI holds it to 250px) have handlers in `SpecialController`; behavior table in `docs/specials_backlog.md`. **Disarm status** (Chill Out, Man — zero damage, 20s dead triggers): strips fire intent at the stun seam, purple peace marker + dimmed HUD rack, `fixed_loadout` bosses immune, GLITTER impact style, replicated as a snapshot flags2 bit. Per-car `burn_taken` multiplies burn DoT (Lovebug 1.5). Burns show hull-fire FX; **boost extinguishes burn** (play mechanic).
- **Free-for-all:** every vehicle (player and all AI) can damage every other — no teams. The only immunity is a shooter to its own fire; AI may engage any combatant. AI runs the player's full loadout at 3× mount cooldown (`WeaponMount.cooldown_scale`), line-of-sight gated. **Balance intent: AI brawls are theater, kills belong to the player** — AI-on-AI damage runs at 0.35× and a fellow AI under 10% HP is *immune* to AI damage entirely (`Vehicle.combat_scale`); targeting is unrestricted, so the shooting never stops — it just can't finish. The player deals/receives full damage and carries a small targeting-priority bonus. Knobs: `AI_VS_AI_DAMAGE`, `AI_MERCY_HP` (vehicle.gd), `PLAYER_PRIORITY` (enemy_driver.gd).
- AI archetypes: **aggressor** (charges the nearest, fights to near-death), **ambusher** (flanks, hit-and-run), **opportunist** (stalks the weakest car, pounces, flees early) — expressed as a **blendable weight mix** `Vector3(aggressor, ambusher, opportunist)`, so pure types and any hybrid (e.g. brawler-jackal) share one system; traits (range, flee, flank, target scoring) interpolate. Plus tougher **mini-boss/boss** variants. Not a passive "defender." Drivers carry **obstacle feelers** (raycasts vs walls/blocks — never cars; ramming is gameplay) and an **unstick reverse-out** when pinned; all AI tuning lives in `enemy_driver.gd`'s `PURE` table; per-car archetype is authored as `ai_archetype` in `roster.json` (the level_loader shim maps it to mix weights). (`assets/data/ai_profiles.json` is design notes only, not consumed by code.)
- **AI is perpetual-motion** (test-locked by `tests/test_no_camping.gd`): empty scan → HUNT the nearest combatant anywhere (parking is never a strategy); close spacing → a committed **BREAK** arc (drive-by pass), not a retreat; long approaches weave on a per-driver phase; damage records `last_attacker` for **revenge targeting** (+0.5 score); dry hunters **scavenge** the nearest crate; AI burns its own boost tank to close gaps and flee. Two anti-deadlock valves: a stuck trip with clear feelers and a non-player car in contact = **antler lock** → shun that opponent 4s (both elk re-target elsewhere; player exempt, only-combatant fallback); a second failed reverse-out at the same pin earns the **escape hop** (`Vehicle.escape_hop` — jump-mine-style pop over the obstruction toward the fight, 6s cooldown). **RELENT** (player-only pressure relief): 6s of in-range LoS engagement or 30 player HP lost while engaged → 3.5s no-fire disengage arc (`ENGAGE_LIMIT`/`RELENT_DAMAGE`/`RELENT_TIME` knobs).
- Environmental destruction, verticality (jump pads, ramps, multi-floor terraces, pits), scavenging.
- Seven progressive levels (six arenas + one forced-scroll chase), tutorial arena through final boss.

## Architecture

- **One vehicle, two drivers.** A single `Vehicle` (CharacterBody2D) owns all physics, health, and weapons. A `Driver` supplies intent; `PlayerDriver` reads input, `AIDriver` runs a behavior FSM. Physics lives exactly once — player and AI never duplicate it. (The retired build's two ~1,700-line vehicle monoliths are the mistake this prevents.)
- **Data-driven content.** Vehicles, weapons, and AI profiles are typed `Resource` files; adding a car or weapon is a `.tres`, not code. Surface identity follows the same rule: `VehicleTerrainModifier` entries are authored under `terrain_modifiers` in `assets/data/roster.json` and imported into `VehicleStats`; omitted surfaces/properties are neutral ×1.0.
- **Physics:** CharacterBody2D arcade driving with velocity decomposition + lateral-friction grip; per-vehicle feel comes from data, not forks. `DrivingController.effective_terrain()` is the sole composition seam: mutable global surface accel/top/grip/steer × the ride's typed profile, identically for player and AI. Ice is worldwide spinning-tires oversteer (0.55 accel / 1.00 top / 0.08 grip / 1.20 steer): the nose rotates eagerly while momentum keeps traveling. A per-car **mass** stat (1–10, roster.json) shapes launch, coast, and braking (heavy = slow launch, long coast, soft brakes); `LCtrl` handbrake cuts lateral grip for drift. **Straighten assist**: hands-off past `straighten_delay` (0.35s slip grace) boosts lateral grip and eases heading onto the 16-step visual grid — post-corner slip breathes, then the car tracks straight (knobs in `driving_controller.gd`, per-car via `handling_overrides`). Cricket gains on dirt and modestly on grass; Hammertoe's big tires and Smoky/Razorback's 4WD blunt non-ice penalties. Cricket's dirt profile also authors generic `dash_damage = 1.15`; every DASH snapshots that factor at activation until its first impact or reset, with no car-specific branch. Feel bands are test-locked in `tests/test_driving_controller.gd` and `tests/test_terrain_profiles.gd`; history + current model in `VEHICLE_PHYSICS_PROGRESSION.md` (Phase 4 = the rebuild).
- **Terrain-profile authoring recipe:** add surface entries to the car's `terrain_modifiers` object in `assets/data/roster.json`, run the roster importer (`godot --headless --path . -s res://tools/import_roster.gd`), and verify the live surface plus effective accel/top/grip/steer in the F1 handling dashboard before running the terrain feel tests. Unknown terrain names and properties fail import instead of becoming dead data. Tune global surface values in F2 when every car should move; tune roster factors when only one ride should.
- **Rendering:** 2D sprites, GL Compatibility, nearest-neighbor filter; fake depth via a separate shadow sprite + height offset + per-level Y-sort.
- **Sustained-special timing:** `WeaponDef.active_duration` data-drives BEAM/FLAME runtime. Taser and Blunt Blaze are 2s bursts followed by a shared 15s `SpecialController` lockout whose clock starts only when the running effect ends (including an early beam break), never while it fires. Lackey's twin barrels share the lockout; player and AI use the same actual gap (no AI/difficulty scale). This is separate from `WeaponRack` charge regeneration: Smoky 90s / Bumper 90s / Lackey 120s, caps unchanged.
- **Proximity readability:** Land Mines paint a 14px disc but fuse at 52px; Jump Mines retain a 26px contact sensor. Ammo, heal, and boost pickups all collect on a 36px surface and instance the cosmetic-only `pickup_cue.tscn`: same-layer contrast ring (7px dark under-stroke + 4px hot pink face) behind the existing letter/icon, breathing center→36px at 18 pulses/minute without exceeding collection range. Custom/editor ammo inherits the shared scene automatically.
- **Repair bays:** square health stations snap a damaged human car to center for a fixed 2s linear refill. `Vehicle.begin_repair_hold` owns the solid/disarmed physics pin and snapshots the complete world velocity vector + heading; the station owns HP timing, uses, and the level-wide 45s cooldown. Four procedural blue-white corner bolts converge on the cross while the rest of the fight continues. Successful completion restores the saved motion and grants the exact shared 2s respawn blink shield with no immunity gap; cancellation/death/tree exit restores neither momentum nor shield. `Health.set_immunity` composes the bay hold with status/DEVGOD instead of fighting `StatusReceiver`. LAN protocol 6 mirrors repair state in the spare row flag and binds puppet FX to the nearest station; streamed HP/motion remain authoritative. One-shot chase medkits stay instant drive-over pickups.
- **Screen layout:** fullscreen on a 1280×720 base viewport — a centered **720×720 play square** with opaque 280px gutters (`ui/hud.gd`): left = dash (HP/speed/MG heat/boost/weapon slots/keyguide), right = full-arena north-up minimap (`ui/radar.gd` — geometry duck-typed off collision layers; enemy blips range-limited to 1500px) + opponent roster with health bars. `ui/offscreen_tracker.gd` projects every other live combatant through the active canvas transform; paint-colored, contrast-outlined triangles clamp 14px inside the play rim with boundary hysteresis and overlap spreading. Meaningful (≥1) nonfatal hits authored by the local viewer pop only the rate-limited 0.22× outer explosion ring on an active marker; fatal hits bypass the cooldown and use the complete small burst. Onscreen, DoT, and other-attacker hits do not cue. ESC pause menu in `ui/pause_menu.gd`; win/lose end screen in `ui/end_screen.gd`. Camera zoom: combat 0.62 / G-toggled 0.42 overview, lerped in `vehicle.gd:_process`; values + toggle state live on `GameState` (`zoom_combat`/`zoom_overview`/`overview` — the proto-settings surface, persists across levels/respawns/campaign resets).
- **Collision layers** (named in project.godot): 1 = ground (vehicles, dummies), 2 = wall (arena boundary), 3 = obstacle (blocks/cover — airborne cars and `pierces_cover` projectiles ignore it), 4/5/6 = floor_low/mid/high (terrace bits — see multi-floor below), 7 = hazard_edge (`environment/hazard_curb.gd` — AI-feeler-only rails along lethal rims; nothing else masks it), 8 = terrain zones (road/grass/snow/dirt/ice/water, composed with per-vehicle profiles in `driving_controller.gd`), 9 = floor_tag (`FloorZone` ↔ `FloorSensor`), 10 = soft_target (nonblocking ambient people/animals/props).
- **Multi-floor terraces** (`game/floors.gd`, dependency-free like combat.gd): floor levels tag regions with `FloorZone`s (1 = sea level, 2 = street/dock, 3 = rooftops); every XY point has ONE driveable floor (nothing drives under anything). `Vehicle.floor_index` (-1 = legacy level, masks bit-for-bit classic) keeps bit 1 in its layer plus its floor bit; grounded mask = wall + own floor bit, so cross-floor cars and other floors' walls don't physically exist. All grounded layer/mask decisions live in `Vehicle._apply_ground_collision()` (SpecialController duck-types `current_ground_mask()`). Transitions: drive past a lower zone's seam = ledge hop down (free for 1 floor; 2+ floors = `fall_damage_frac` 25% max HP, F2-tunable); going UP is landing there (jump pads) — a higher sensed floor while grounded is ignored, walls own up-boundaries — **except on driveable GRADES**: rectangular `Ramp` and triangular `CornerRamp` build ramp-tagged low/high FloorZones, adopt at ground level both ways, and never hop or bill fall damage. Every ordinary grade carries a 120 px/s² downhill pull (up slows, down accelerates); its high-priority local `terrain_type` then composes road/grass/snow/dirt/ice/water handling deterministically over broad background zones. Coliseum seating is the protected exception: explicit pull 170 + `stairs` row nicks/bumps. `CornerRamp` uses a high right-angle vertex and low 45° hypotenuse; `TerraceChamfer` is the matching SOLID top-side triangle carrying both floor bits. Four cardinal + four corner grades are the accepted eight-sided circular-hill approximation (Snowy summit). Side rails remain for chokepoint ramps and are disabled for continuous hills. Floor-3 cars hold a **32px visual lift** (`Vehicle.FLOOR_LIFT`) with the shadow riding the terrace beneath them (tight while driving; body/shadow separate only on real jumps) — climbing a grade visibly rises. Size cue: visuals scale 0.94/1.0/1.06 by floor (`Floors.VISUAL_SCALE`), radii untouched. **Weapon gating is physical**: straight shots fly with mask wall+own-floor-bit (cross-floor cars never even signaled); tracking weapons (turn_rate>0 + acquisition>0) can reach any floor but include cover bits for the shooter's floor and locked target's floor, omitting only intermediate terraces. Explicit `pierces_cover` shots retain boundary-only flight. BEAM/FLAME/DASH/mines/barrel blasts filter same-floor in code. AI: feelers/LoS go floor-aware (all car RIDs excluded — floor bits ride car layers), `Mode.NAVIGATE` rides authored `FloorConnector` markers cross-floor, roof snipers hold vantage ~8s with tracking secondaries. Roof/deck spawns author `start_floor` (a legacy-mask boot inside a warehouse would push out). **Draw order carries the depth read**: floor-3 and airborne cars ride `z_index` 2, overhead paint (sky bridges, crane booms — `dock_deco.gd`) sits at z 1, everything else stays z 0 — which is also what makes over/under structures render correctly. Jump pads game-wide are omnidirectional caution-striped pyramids (`environment/jump_pad.gd`, class `JumpPad`, square 224 Cols, `Vehicle.launch_from_jump`); on terrace levels each pad carries `floor_index` and only launches cars on its own floor (a roof car can never trip a street pad) — author pads clear of building footprints regardless (locked by `tests/test_dock_level.gd`). `FloorConnector` kinds: &"jump" (boost run-up) / &"grade" (driveable grade, no boost) / &"edge" (drive off).
- **Driveable hills:** `environment/driveable_hill.gd` is the one-root/eight-face authoring primitive: summit floor+terrain, four paintless `Ramp`s, four derived `CornerRamp`s, all paired connectors, and one clipped-octagon skin. `grade_length` alone owns slope depth; corner leg is always half. Compact hill facets default to pull 180 (short crossing); standalone ramps remain 120 and Coliseum stairs 170. The skin resets the substrate before applying the matching terrain once, then adds static NW relief 0.22, pattern projection 1.55, all-slope darkening 0.06, broad crest/foot gradients, and a `(12,14)` SE contact shadow at 0.20 alpha. Ordinary grades duck-type `visual_floor_at()` so every local/AI/network car and its tight shadow interpolate lift 0→32px and scale 1.0→1.06 without touching collision; `stairs` opts Coliseum out. Hill content stays parented to the root. A prop crossing a grade seam draws after the skin and carries both floor bits. Full authoring/failure contract: `docs/arena_field_manual.md`.
- **Destructibles:** any body with a `Health` child takes weapon fire and speed-scaled ram damage; `environment/destructible_block.gd` is the reusable obstacle flavor (layer 3, exported size/HP; `deco` picks the paint — house roof / crate / kiosk / barrier / guardrail / junk / gas pump / **picket fence** (15 HP) / **fuel barrel**, and barrels detonate: 130px blast, 25 flat damage to anything Health-bearing, chains included). `environment/clutter.gd` is the 1-HP pop-through flavor (trash/brush/bush/drift blobs + street furniture: mailbox/sign/cone/bike/**hydrant** — hydrants erupt an 8s water fountain; size-gated off the radar). `environment/derelict_car.gd` = 50-HP abandoned roster cars (real CarPaint, drab seeded palettes). Pure paint/FX layers: `environment/road_marks.gd` (dashed lines/crosswalks) and `environment/street_deco.gd` (traffic lights, neon, streetlight pools, manhole steam, snowfall) — non-colliding by design so AI feelers never see them.
- **Living streets:** `AmbientPopulation` authors deterministic wander zones, looped point routes, or stationary groups; `AmbientActor` supplies procedural animation, bounded movement, wall probes, light vehicle scatter, floor awareness, and 1-HP soft-target presentation. Current populations: Downtown 18 figures + 2 carts, Suburbs 18, Snowy Pass 7, Docks 18. Actors never join combat groups, block cars/shots, change scores, or appear on radar. Real projectiles pop them but continue flying; police tracers are LoS-gated and explicitly harmless. Living targets leave a 5s splat; crossing it gives `DriveFX` 1.25s of red rear-tire tracks (bike one line, cars a pair), fading over 3s under the shared skidmark cap. Ambient movement/death is cosmetic-local in LAN; no protocol state exists.
- **Impact presentation:** `Projectile.impact_style` is scene-authored (`SPARK`, `MISSILE`, `NONE`); soft-target pass-through overrides presentation to `SPATTER`. `impact_fx.tscn` is pooled, visual-only, short-lived, and never adds damage/shake/bloom/sound. Every ordinary body/wall hit is terminal even without Health; soft-target hits are not. In LAN, host-assigned u32 shot IDs ride projectile births and `EV_IMPACT` carries position/style/terminal state; clients always show the authoritative effect and retire only matching terminal visual twins.
- **Performance:** 60 FPS locked on mid-range GPUs.
- **Packaging:** AppImage for Linux.

## Code standards

- **File size:** ≤1200 lines excellent; 1700 is a hard stop — pause and modularize. Shared logic lives once; never duplicate player/AI or weapon logic.
- **Idiomatic Godot 4:** typed `Resource` classes, `class_name`, and composition are expected. (The retired build banned `class_name` to cope with a tangled codebase; that ban is dropped — a clean dependency graph plus the CI parse gate is the real protection.)
- **Validate InputMap actions on boot** — carried-forward safety against missing-action regressions.
- **After any script change, run the smoke gate:** `tools/smoke.sh` (headless import + boot; fails on parse errors, failed loads, or missing autoloads) **and the unit tests:** `tools/test.sh` (headless suites in `tests/`, driven by `tests/run_tests.gd`). CI runs both on push/PR via `.github/workflows/smoke.yml`.

## Level progression

**Shipped campaign** (`SceneFlow.CAMPAIGN`, all hand-authored scenes sharing `levels/combat_level.gd` — lives loop, level-start blink shield, enemy re-roll, menus): regular-map contract lives in `docs/arena_field_manual.md` + `levels/arena_contract.gd`. Absolute floor = 4 target cars, 1.6M px² gross per target car, short side ≥2048; small/med/large = 4 / 5-7 / 7-8 total cars and 1 / 1-2 / 2-3 health stations. Boss overlays may campaign-field two actors but still declare ≥4 arena capacity. Buzzard is specialty-exempt; Depot/Coliseum are the only named temporary MP exceptions.

1. **Downtown** (MED, 4 enemies, 1 station) — the city arena: park, secrets, courtyard. **Multi-floor retrofit**: the NW+N blocks are driveable rooftops joined by a sky bridge; an asphalt garage ramp grades up BuildingN's south face; the jump pad launches onto the NW roof; roof crates reward the trip.
2. **Freeway Loop** (LARGE 2176×5376, 6 enemies, 3 stations) — NS ring road, infield crossover, low-HP guardrails, overpass jump pads.
3. **Suburbs** (MED, 6 enemies, 2 stations) — smashable houses on grass blocks, school/gas-station anchors, lakeside east edge.
4. **Snowy Pass** (MED, 6 enemies, 1 station) — snow/ice switchbacks and **pit drop-offs** (`environment/pit_zone.gd`: grounded cars fall; jump launches clear them). **Multi-floor hill**: one `DriveableHill` at `(896,-672)` fits exactly between the roads (848px summit + 240px grades = 1088px footprint), keeps its slick summit rewards/deer, shades all eight faces as one surface, and integrates the dual-floor slope building without losing any paired AI route.
5. **The Depot** (MED, miniboss) — **Lackey**: 1.5×-scale, roster-external (unselectable; `fixed_loadout` skips the car re-roll), `rear_weakspot` 1.75× on shots arriving from behind. His **Breach Cannon is a LIVE turret** (`weapons/turret.gd`, data-driven via `VehicleStats.turret`): auto-aims the player independent of hull heading (own global_rotation — immune to the 16-step visual quantization), 45-dmg power-class shot every 2.8s inside ~1100px, 120°/s traverse (aim lag = the dodge), LoS-gated, and it keeps firing through break-offs (fighting retreat). Special is the **Blaze & Bolt twin** — Blunt Blaze + Taser sharing ONE ammo pool (`special_b` on VehicleStats; one rack slot, two defs, one counter; SpecialController picks per activation: latchable target ⇒ taser, else torch), cap 2 / 120s; either 2s burst locks both barrels for 15s afterward. `no_mines` locks his mine slots at 0 (crate-proof). **Boss pressure valve**: after dealing ~`BOSS_HIT_BUDGET` (50) to the player or 7s of pressure he BOOSTS a break-off arc — rear exposed — breather dominance-scaled 2.0–5.5s; bosses run FULL-length spacing arcs (the old half-length arc was the close-combat suffocation). Arena: destructible mixed-livery container cover (140 HP — the yard opens up as the fight rages), chain-link perimeter runs, bollards, barrel clusters, stop-line containment square, streetlights + steam. Knobs in `enemy_driver.gd` / `lackey_cannon.tres` / `lackey.tres`.
6. **The Docks** (LARGE 5120×3584, 7 enemies, 2 stations) — the first **multi-floor** level: west dirt/grass lowland (floor 1) below a retaining wall, warehouse streets and quay (floor 2), five jump-pad-served rooftops + a 1704px container-ship deck (floor 3, boarding = a pier-end stunt jump over dredged water). Two **sky bridges** (W1↔W2, W5↔W6) and the crane booms are overhead layers — drive over on floor 3, under on floor 2 (the terrace max rule + z-order make it free). South edge is **deep water** (`environment/deep_water_zone.gd` — pit-style sink kill with splash + rising bubbles; airborne clears; shallow beach buffer at the natural shore) broken by piers, fronted by smashable 12-HP **chain-link** fence runs; hazard curbs keep AI off the rims. Mixed-livery container yards (`livery` export) dress the quay. Not the finale — more levels follow.
7. **The Buzzard Run** (CHASE, ~130k px streamed, runtime horde) — the first **forced-scroll game mode**: 180 seconds north up a seeded highway, survive to win (`buzzard_run.gd` extends combat_level; timed win drives `end_screen._show(true)` directly — `suppress_group_win` blocks the arena-style poll, which a wiped wave would otherwise trip). **Course**: `chase_course.gd` pre-rolls a 130k-px plan from `chunk_defs.gd` (15 defs: sweepers, chicane w/ rail spine, divided carriageway, narrows, slalom, potholes, log runs, jump-pad launch lane, pickup lanes, and three RARE landmarks spaced ≥15k — overpass (deck paint at z 1, shadow at z −1 — drive under, thread the pillar walls), neon truckstop, crashed convoy); ## Multiplayer (LAN, v1 — July 2026)

**Host-authoritative listen server: the host IS single-player, broadcast.** Host simulates every car through the existing Driver seam (`PlayerDriver` self / `NetworkDriver` per remote seat, replaying streamed 8-field intent dicts / `EnemyDriver` melee backfill); clients render EVERY car — including their own — as an interpolated **puppet** (`Vehicle.set_net_puppet`: sim bypassed, collision zeroed, subsystem ticks off, hp lands direct on Health never take_damage, same 16-step visual tail; `NET_INTERP_MS` render-behind, ~1.25-sample extrapolation). No prediction — LAN-first, direct IP works over a forwarded port. 4 seats + 8 observers = 12 ENet peers.

- **Stack** (`game/net/`, siblings preloaded BY PATH — bare autoload/class_name identifiers die on the test runner's `-s` preload chain): `net_session.gd` (autoload `Net` — peer lifecycle, all RPC planes, roster/config/actor-table state; MP state NEVER touches GameState), `net_protocol.gd` (PROTOCOL_VERSION 7 gate — bump on any wire change; ports 42998/42999; `snapshot_hz` 30 / `input_hz` 60 / `interp_delay_ms` 50), `net_auth.gd` (pre-admit SceneMultiplayer handshake: banlist → nonce challenge → salted proof, password never on the wire; checksum ⇒ MODDED flag or strict-reject; rejects ride `peer_disconnect_later` flush-then-cut — instant disconnect races the reason), `net_manifest.gd` (CRLF-normalized script-source hash — presets ship scripts as TEXT for this), `net_banlist.gd` (user://banlist.json), `net_roster.gd` (seats/queue — **queue integrity is structural: every exit forfeits position**), `match_config.gd` (normalize() clamps every host edit), `net_snapshot.gd` (StreamPeerBuffer codecs: 7-byte intent frames; ~26B/car rows in ACTOR-TABLE ORDER — the table is the index; seven ammo counters + brake/repair state mirror + a flags2 byte (disarm); weapon-cycle edges ride reliable seq'd RPCs, never the unreliable frame), `net_events.gd` (host-armed projectile, meaningful-hit, and impact taps — projectile births carry u32 shot IDs; visual-only client twins deal 0 damage; terminal impact events retire mapped twins; hits replicate as attacker/victim actor pairs for personal edge confirmation; never MultiplayerSynchronizer), `match_director.gd` (host-only, Net-free: formats via pure static `end_check`, 10s `last_attacker` attribution window — the Vehicle setter stamps `last_attacker_ms` — rotation on the unified seat-fill rule, match-end BEATS rotation, creditless `vacate_actor` on disconnect), `net_discovery.gd` (UDP beacon/browse, one browser per box).
- **Flow**: title MULTIPLAYER → `ui/mp_menu` (callsign/host/join) → host detours through car_select (MP-aware confirm/ESC) → `ui/mp_lobby` (two-column, border LOCKED to measured worst case — content top-flows; host auto-seats SEAT 1; CHANGE RIDE = the carousel; OBSERVERS/GOT-NEXT paired rules) → `levels/mp/mp_match` (shell: arena instanced with `combat_level.mp_managed` — baked cars become spawn data and free pre-first-tick, zero .tscn edits; NEVER instantiates pause_menu/end_screen — `ui/mp_pause_overlay` never pauses the tree) → `ui/mp_scoreboard` → lobby, looping. `SceneFlow.MP_MAPS` = the five standard arenas with authored `cars` counts (boss arenas need their scripts stood down first). Observers/eliminated/rotated-out ride `levels/mp/spectator_rig.gd` (follow-cycle + free-roam + G zoom).
- **Locked policies**: **ONE of each car on the battlefield** — claimed set = seated + queue picks, enforced at every host entry point; AI pool excludes it (short pool = fewer bots, never dupes); carousel tags [ TAKEN ]. ## Development workflow

1. Work narrow and deep: one drivable system at a time, vertical-slice first (driving feel before breadth).
2. Keep changes scoped; match the existing style of the file you edit.
3. Hold the 16-bit dystopian aesthetic and per-vehicle distinctiveness while keeping top-down combat readable.
4. Run `tools/smoke.sh` after script changes; keep files under the size ceiling.
