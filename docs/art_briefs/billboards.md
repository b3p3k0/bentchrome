# Route 666 billboards: art brief

The parody ads along Route 666 (`levels/chase/highway_deco.gd`, kind
`billboard`, copy from `BILLBOARD_COPY`) are the ONE place the game's signage
is allowed to be silly. A text board reads fine; an illustrated one pops. Each
illustrated board is a drop-in PNG that the game draws as the board's face —
the painting carries the copy, and the game adds the posts, the frame line,
the bulb strip and the sunset's long shadow around it.

Drop-in contract and slug rule: `assets/img/billboards/README.md`.

## The three rules

1. **The slogan is the joke.** The copy is painted ON the board as big
   sign-painter's lettering, spelled EXACTLY as the table has it — same
   capitals, same punctuation, nothing added. A board whose copy the model
   keeps misspelling falls back to the text board; a wrong letter is a reject.
2. **One strong image.** Each board is one picture a driver can read at 0.55
   zoom while a horde eats their bumper. No scenes, no clutter, no fine print.
3. **The house look is 16-BIT PIXEL ART** — `assets/img/cards/level_1.png` and
   `story/splashscreen.png`, not the inked-comic bio portraits. Chunky visible
   pixels, limited palette, dithered shading, grimy and sun-faded. Snarky,
   sarcastic, never grim.

## Format

- **1360×520, landscape, opaque.** 4× the 340×130 board, drawn at the chase's
  0.55 zoom with nearest filtering (the project default — `project.godot`
  `textures/canvas_textures/default_texture_filter=0`), so it reads crisp on
  the way down. Nothing transparent: the frame is drawn over the edge.
- **A flat matte of the board's colour** fills the face; the picture and the
  lettering sit on it. No frame, no posts, no sky, no road — the game draws
  the mounting.
- **Keep the outer 6% free of anything that matters**: the game's frame line
  runs 8 world px in from the edge.
- The image model paints 3:2 (1536×1024). The brief tells it the board is the
  middle 56% band and to fill the strips above and below with matte;
  `tools/billboard_brief.py --normalize` crops the band and scales it to
  1360×520.

## Generating a board

Boards are generated by Codex's built-in image tool, one image per brief,
with the level-1 loading card attached as the style reference. Codex is not
on `PATH`; it ships inside the VS Code extension, and only the 26.810 build
starts its sandbox on this host (test with `$CODEX sandbox -- /bin/ls`).

    CODEX=~/.vscode/extensions/openai.chatgpt-26.810.52044-linux-x64/bin/linux-x86_64/codex
    cd assets/img/billboards/source
    ../../../../tools/billboard_brief.py wanted \
        | $CODEX exec --skip-git-repo-check -s workspace-write \
            -i ../../cards/level_1.png -
    # writes ./wanted.png (originals also land in ~/.codex/generated_images/)

Review the take against the checklist below, then normalize the keeper into
place (the band crop + the 4× resize, matte forced opaque):

    ../../../../tools/billboard_brief.py --normalize wanted.png ../wanted.png

Then run `tools/smoke.sh` once: it imports the project, and Godot's import
cache does not pick up a new PNG on its own.

To change a picture, edit its entry in `tools/billboard_brief.py` and rerun.
To repair one detail of a board that is otherwise right (one wrong letter, a
stray word), attach the board itself with `-i` and name the single change
plus everything that must stay; rerolling loses the composition you had.

## Review checklist

| Check | Reject if |
|---|---|
| Lettering | any letter, capital or mark differs from the table; a word added or dropped; a second copy of a line |
| Read | the slogan or the picture doesn't read at a glance at the chase zoom (view the normalized PNG at ~190 px wide) |
| Band | anything that matters crossed the crop band or sits in the outer 6% |
| Style | smooth gradients, photoreal, 3D, clean vector, or the inked-comic portrait look instead of pixel art |
| Matte | the face isn't an opaque flat matte; a frame, posts, sky or road were painted around it |
| Tone | grim instead of silly; gore; a real brand, logo or mascot |
| Size | the installed file isn't 1360×520 |
