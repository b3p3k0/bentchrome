# Boot sequence drop-in folder

Everything the startup cards show and play (`ui/boot_splash.gd`). Same
contract as `assets/sfx/` and `assets/bgm/`: the name IS the wiring, and an
absent file never breaks the launch — a card without art falls back to its
text lines on the matte, a sting without a file runs silent.

| File | What it is |
|---|---|
| `card_fony.png` | card 1, white matte: `FONY` / F diamond / `COMPUTER ENTERTAINMENT ™` |
| `card_fanstation.png` | card 2, black matte: F-on-S emblem / `FanStation` / `not Licensed by Anyone` / `IPACRAO™` |
| `boot_sting.ogg` | the one sound under both cards, 14.5s stereo one-shot |
| `source/` | full-size generated art + the briefs that made it (`.gdignore`d — never imported, never shipped) |

The acronym is never spelled out anywhere in the game.

## Rules

- **Copy is test-locked.** `tests/test_boot_splash.gd` pins every string and
  the card order through the `CARDS` table; art is reviewed letter-for-letter
  against the same table before it lands.
- **Any aspect works.** Art is letterboxed over a matte of the card's own
  color, so the matte must be PURE white / PURE black edge to edge or the
  seam shows.
- **Soft on purpose.** Cards ship at 640x360 and the engine upscales them
  with a linear filter (`ART_FILTER`) — the low-res console look. Ship larger
  art for a crisper card.
- **No menu music under the sting.** The boot scene maps to `SILENT` in
  `MusicDirector.TRACKS`; the title starts `bgm_menu` from the top.
- The sting rides the `SFX` bus (the SFX VOLUME slider) plus the `STING_DB`
  trim. It is a scene-owned player, NOT an AudioDirector event — a skip has
  to fade it.

## Regenerating the art

The cards were generated by Codex's built-in image tool from the briefs in
`source/`, one image per brief, then reviewed and normalized here:

    codex exec --skip-git-repo-check -s workspace-write < source/brief_fony.md
    # generated PNGs land in ~/.codex/generated_images/ — copy the keeper to
    # source/card_fony_src.png (same for brief_fanstation.md)

    magick source/card_fony_src.png -white-threshold 96% -resize 86% \
        -background white -gravity center -extent 1536x1024 -resize x720 \
        -extent 1280x720 -filter Lanczos -resize 640x360 card_fony.png
    magick source/card_fanstation_src.png -black-threshold 4% -resize x720 \
        -background black -gravity center -extent 1280x720 \
        -filter Lanczos -resize 640x360 card_fanstation.png

The thresholds force the matte pure; the FONY card's `-resize 86%` gives the
emblem its breathing room; the final `-resize` is the softness knob.

To repair one detail of a card that is otherwise right, EDIT it instead of
rerolling: attach the source art and name the single change plus everything
that must stay. `source/brief_fony_fix.md` is the pass that squared up the
diamond's right point; `source/brief_fanstation_fix_pass1.md` then `_pass2.md`
are the two passes that turned the FanStation base into a slim ribbon S
(pass 2 edits the result of pass 1). Those passes also attached a reference
screenshot as a shape guide for the S only; it is not kept in the repo.

    codex exec --skip-git-repo-check -s workspace-write \
        -i source/card_fony_src.png < source/brief_fony_fix.md

Editing needs a Codex build whose sandbox can read the attachment. Keep
emblem geometry clean in briefs: an art-directed "dent" on the diamond read
as a rendering glitch, not a joke, and was removed.

## Regenerating the sting

    ./venv312/bin/python tools/synth_boot.py              # render the sting
    ./venv312/bin/python tools/synth_boot.py --wav-only   # audition /tmp/boot_sting.wav
    ./venv312/bin/python tools/synth_boot.py --no-bend    # the straight take

An ORIGINAL homage to a mid-90s console power-on — pure synthesis on the BGM
engine (`tools/bgm/engine.py`), nothing sampled, built from the composer's
own public description of the form. One shot, not a loop.

| Time | On screen | Sound |
|---|---|---|
| 0.0-6.4s | FONY fades in and holds | sub drone from silence; string ensemble on the dominant (Gsus4) blooms as the filter opens |
| 6.4-7.4s | FONY fades to black | air rises into the turn |
| 7.4s | black | floor-drop thump; tonic (Cadd9) lands |
| 7.6-11.9s | FanStation fades in and holds | glass chimes climb in fourths, a strummed quartal chord, then sparkle |
| 11.9-14.5s | FanStation holds, fades out | the last chime sags flat and gives up; tail to silence |

The cue points at the top of `tools/synth_boot.py` mirror `TIMING` in
`ui/boot_splash.gd` — move them together. `BEND` (semitones, default -1.6)
is the parody knob: the final chime droops like a knockoff console's cheap
DAC; 0 plays it straight.

`pip` deps as for the BGM tools (numpy, scipy, pedalboard). Pin
`pedalboard==0.9.22` if a newer wheel dies with "Illegal instruction" on
import (0.9.25 does on 12th-gen Intel).
